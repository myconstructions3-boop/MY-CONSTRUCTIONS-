MY CONSTRUCTIONS - GitHub Pages website

PUBLISH:
1. Sign in to https://github.com and create a public repository named my-constructions.
2. Choose Add file > Upload files, then upload ALL files in this folder (index.html, style.css, about.html, services.html, railway-works.html, projects.html, contact.html, README.txt).
3. Commit changes.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; branch main; folder /(root); Save.
6. Wait for the Pages URL shown on that screen, usually https://YOUR-USERNAME.github.io/my-constructions/.
7. To connect myconstructions.in, add it in Pages > Custom domain and configure DNS at your domain provider. DNS values are shown in GitHub's current documentation/settings; enable Enforce HTTPS after DNS verifies.

IMPORTANT:
- This is a static HTML/CSS site. It does not run WordPress/PHP and does not include a database/admin dashboard.
